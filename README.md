## 목표

### 1차 목표

- 삼성 SW 역량테스트 **A형 취득**
- Java를 활용한 알고리즘 구현 능력 향상
- 빈출 유형의 기본 풀이 방법 숙달
- 제한 시간 내에 문제를 분석하고 구현하는 능력 향상
- 삼성 SW 역량테스트 스타일의 구현·시뮬레이션 문제 대비

- 다양한 기업의 코딩테스트에 대응할 수 있는 문제 해결 능력 확보
- 자주 사용하는 알고리즘을 Java로 직접 구현
- 풀이의 시간 복잡도와 공간 복잡도를 분석하는 습관 형성
- 오답과 어려웠던 문제를 반복해서 복습
- 풀이 과정을 논리적으로 설명할 수 있는 수준 도달

## 커밋 메시지 규칙

| 커밋 유형 | 설명 |
|---|---|
| `solve` | 문제 풀이 완료 |
| `unsolved` | 문제를 해결하지 못한 미완성 풀이 저장 |
| `retry` | 문제 재풀이 |
| `fix` | 오답 또는 코드 수정 |
| `docs` | README 및 문서 수정 |
| `refactor` | 풀이 코드 개선 |
| `template` | 알고리즘 템플릿 추가 |

### 사용 예시

```text
solve: BOJ 2309 일곱 난쟁이
unsolved: BOJ 17472 다리 만들기 2
retry: BOJ 14502 연구소
fix: BOJ 2304 인덱스 범위 오류 수정
docs: week01 README 문제 현황 수정
refactor: BFS 방문 처리 로직 개선
template: 조합 알고리즘 템플릿 추가
